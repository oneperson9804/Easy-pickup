# 素材说明

视觉规范更新日期：2026-10-25。

整体以青色灵力为主调，搭配万年金雷竹的沉金色泽、竹节纹理与细微雷光。浅色界面保持通透，深色界面使用深青底色；文字和取件码优先保证清晰。

| 素材 | 位置 | 设计 |
| --- | --- | --- |
| 应用图标 | `assets/branding/app_icon.png` | 包裹与竹叶形成简洁主体，青色灵力环绕，沉金雷纹点缀 |
| 空状态插画 | `assets/branding/bamboo_empty.png` | 透明背景的包裹、竹叶与细金雷光，适合小尺寸展示 |

插画用于空状态和必要说明，功能按钮与取件内容由界面组件直接呈现。标准平台图标的尺寸配置见 `pubspec.yaml` 中的 `flutter_launcher_icons`。

项目图标和插画随项目许可证发布。第三方组件、平台名称及商标适用各自的权利声明。
